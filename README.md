# MultiPiP Top

## 使用方式

1. 在分頁播放影片 → 點工具列的插件圖示 → 右下角出現小窗並自動置頂。
2. 到另一個分頁重複，第二個小窗會錯開位置出現。焦點留在原本的分頁。
3. 小窗操作（滑鼠移入顯示控制列）：

| 操作 | 方式 |
| --- | --- |
| 播放／暫停 | 點影片、▶ 鈕、空白鍵 |
| 靜音／音量 | 🔊 鈕、音量滑桿、`M`、↑ ↓ |
| 進度 | 進度列、← → 各 5 秒（直播不顯示進度列） |
| 置頂開關 | 右上「已置頂／未置頂」鈕、`T`。只影響這個小窗 |
| 關閉 | ✕ 鈕、`Esc`、視窗標題列 |

- 同一分頁再點一次圖示 → 聚焦已開的小窗，不會重複開。
- 關閉來源分頁 → 對應小窗自動關閉、串流釋放。來源頁重新整理 → 小窗顯示「重新連線」。
- 聲音由來源分頁播放；小窗影像本身靜音，避免重複出聲。
- 小窗標題結尾的 `pip#xxxxxx` 是識別碼：host 會確認 Edge 給的視窗代號標題中含有它，才執行置頂。
